## 🛠️ Pre-Flight Recording Checklist (2-Minute Setup)

Follow these steps before pressing record on OBS Studio, Loom, or Windows Game Bar (`Win + G`):

1. **Local Server Ready**:
   - Ensure the application is actively running on port 5176:
     ```powershell
     npm run dev
     ```
   - Open Chrome or Edge and navigate to: `http://localhost:5176/`
2. **Display & Resolution**:
   - Set display resolution to **1920 × 1080** (1080p, 16:9).
   - Set browser zoom to **100%** (press `Ctrl + 0`).
   - Maximize the browser window (or press `F11` for clean full-screen presentation).
3. **Audio Capture**:
   - Ensure your screen recording software captures both:
     - **Microphone**: Your voiceover narration.
     - **Desktop / System Audio**: So the offline Swahili and Hausa speech synthesis can be heard clearly by the judges!
4. **Terminal Window Ready (for Air-Gap Disconnect Proof)**:
   - Open a clean PowerShell or Terminal window positioned next to the browser or ready to Alt-Tab.
   - Pre-type: `ping 8.8.8.8` (do not run it yet).
5. **Wi-Fi Toggle**:
   - Be prepared to open your Windows/Mac network tray and toggle Wi-Fi OFF in Scene 1.
6. **In-App Teleprompter (Optional Secret Weapon)**:
   - Click the **"🎬 Pitch Teleprompter"** button in the app's top context ribbon or floating bottom-right pill.
   - It gives you a live stopwatch, word-for-word voiceover cards, and **⚡ 1-click demo buttons** that populate forms and play audio without typing on camera!
   - You can minimize it with 1 click before/during recording.
